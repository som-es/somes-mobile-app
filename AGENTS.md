# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

This project is pinned to **SDK 56**, not the latest. The App Store build of Expo Go does not yet
run SDK 57, and iOS cannot sideload an older Expo Go — so the project targets what Expo Go
supports. Do not upgrade to 57 until Expo Go on the App Store catches up, or until the team moves
to development builds.
